# 领域术语表

信源
逻辑知识库容器，用于归类一组文档并限定检索范围。对应代码标识 `Source`。
别叫：知识库、空间、仓库

文档
导入某个信源的单个文件实体，按内容哈希判重并维护版本号。对应代码标识 `Document`。
别叫：文件、素材

证据包
所有异构输入经解析后产出的统一强类型中间表示，包含原文、结构或时间锚点及附件路径，不提前做有损摘要。对应代码标识 `EvidenceIR`。
别叫：解析结果、摘要

分块
用于向量与词法索引的最小检索单元，保留逐字原文并附带独立上下文头与原文锚点。对应代码标识 `Chunk`。
别叫：切片、段落

事件
从单个分块抽取的语义完整记录，用于动态超边关联索引。对应代码标识 `Event`。
别叫：事实、三元组

实体
从分块抽取的索引词项，用于在查询时通过 SQL 连接共享实体的多个事件。对应代码标识 `Entity`。
别叫：节点、标签

动态超边
查询时按共享实体通过 SQL 动态拼出的局部事件集合，不离线预建全局图谱。对应代码标识 `Hyperedge`。
别叫：子图、社区

入库任务
单个文档从提交到可检索的异步状态机记录。对应代码标识 `IngestionJob`。
别叫：任务、流水线

引用
回答中绑定到具体分块及其原始定位锚点的可验证出处。对应代码标识 `Citation`。
别叫：参考、链接
